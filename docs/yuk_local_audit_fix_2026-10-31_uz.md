## Вазифа (эга сўзлари)

> «Асосий экранда пастки барда "+" тугмаси орқали Менинг бизнесимга кириб Юк ташувчи бўлиш тугмаси босилгандаги занжирни тўлиқ аудитини қил ва батафсил хисоботини тақдим қил»

Аудитдан кейин эга:

- «эълон муддати тугашига 3 кун қолганда эгасига ҳар куни бир марта "3", "2", "1" кун қолди Пушхабар юборилсин»;
- «хақиқий 10 та янги эълон киритилганда намуналар автоматик ўчирилсин»;
- «GPS дан олинсин» (эълон тумани);
- «фойдаланувчига "Эълон қўшиш" тугмаси экран очилганда кўринсин»;
- «топилган Юқори, ўрта ва паст даражадаги барча нуқсонларни тузат».

## Нима ўзгарди

**Илова**
- **Y-1:** `YukModuleScaffold` эга юкланмагунча панелни қурмайди. Шу сабабли ўз эълонлари (муддати ўтганлари ҳам) энди кўринади.
- «Эълон қўшиш» тугмаси экранда доим кўринади.
- Эгага «Узайтириш» тугмаси (деталь варағида ва менюда) ва «Муддати ўтган» белгиси қўшилди.
- Меҳмонга модулда ва асосий экранда «Кабинетда рўйхатдан ўтинг» хабари кўрсатилади.
- Форма:
  - давлат рақами ва сиғим мажбурий;
  - кузов ўлчамлари мусбат сон бўлиши керак;
  - «Бўш/Банд» ҳолатини танлаш мумкин;
  - таҳрирда жойлашув фақат эга ёқса янгиланади;
  - GPS олинмаса, «GPSни ёқиш» тугмаси чиқади;
  - эълонга ёзиладиган исм энди хом исм (аввал «Сиз» ёзиларди).
- Эълон жойланганда «Эълон жойланди» хабари чиқади.
- Хатолар ички код билан логга ёзилади (`YUK_LOCAL_*`).
- Асосий экранда намуна эълонлар «Намуна» белгиси билан чиқади. Қатор босилса ўша машина детали очилади.
- Пуш босилса ўша эълон очилади (`listingId`).
- Сўровлар:
  - мамлакат даражаси `updatedAt` бўйича тартибланган;
  - ҳудудсиз эълонлар аниқ `districtId == ''` сўрови билан олинади.

**Сервер** (`functions/yuk_local.js`)
- `onYukLocalDriverWrite` — триггер.
- `renewYukLocalListing` — callable.
- `yukLocalDailyMaintenance` — ҳар куни 10:00.
- `refreshYukDemoPresence` — энди ҳар 24 соатда ишлайди, `updatedAt` ёзмайди.

**Rules** (`yuk_local_drivers`)
- Телефон эгага боғланди (Y-2).
- `isDemo` ва бошқа сервер майдонлари клиентга ёпилди (Y-3).
- Майдон турлари ва рухсат этилган калитлар текширилади (O-2).
- Ўқиш фақат телефон токени билан мумкин (O-7).
- Анонимнинг бўш `ownerId` билан эълон бериши ёпилди.

**Маълумот** (`functions/tools/yuk_local_backfill_2026_10_31.js`, dry-run → apply)

- 7 та намунага `districtId: gurlan` қўйилди.

## Deploy тартиби ва rollback

1. **Migration `--apply` — эга ўзи ишга туширади.** Production'га ёзишни рухсат тизими рад этди. Триггер бу migration'сиз ҳам тўғри ишлайди: «биринчи эълон» мавжуд эълонлар ва `yuk_local_owner_meta.createTime` орқали аниқланади (A банди ихтиёрий бўлди). B, C ва D бандлари эса шу скрипт ишга туширилгунча бажарилмайди:
   - B: 7 та намунада туман йўқ. Янги иловада улар туман ва вилоят рўйхатида кўринмайди, фақат мамлакат даражасида кўринади.
   - C: муддатсиз эски эълон.
   - D: эски эълоннинг тумани нотўғри.

   Ишга тушириш:
   ```
   NODE_PATH=<functions>/node_modules SA=<service-account.json> BACKUP_DIR=<functions>/tools/backup node functions/tools/yuk_local_backfill_2026_10_31.js --apply
   ```
   Backup `yuk_local_backfill_<runId>.json` га ёзилади. Rollback: `--rollback <file>`.
2. **Functions** (пин `deploy-biz-fns`, номи бўйича): `refreshYukDemoPresence`, `onYukLocalDriverWrite`, `renewYukLocalListing`, `yukLocalDailyMaintenance`. Rollback: аввалги `yuk_local.js` билан `refreshYukDemoPresence`ни қайта deploy қилиш ва 3 та янги функцияни ўчириш.
3. **Rules** алоҳида deploy қилинади. Олдин жонли ruleset олинади ва `functions/tools/yuk_local_rules_patch_2026_10_31.js` билан патчланади. Rollback: аввалги ruleset ID.
4. **Hosting** жонли SHA устига қурилади. Rollback: аввалги build.
5. **APK** — эга рухсатисиз қурилмайди. Мобил иловадаги тузатишлар APK чиққунча ишламайди.

## Эски APK таъсири

- Эълон бериш ва таҳрирлаш ишлайди: rules тести эски APK тўпламини текширди.
- Муддатни сервер тўғрилайди.
- Телефонсиз (аноним) фойдаланувчи эски APK'да рўйхат ўрнида «юклашда хатолик» кўради. Бу эга қарорининг (O-7) оқибати.
