# AVA Zona — транспорт хизматлари (тузатилган)

**Сарлавҳа:** Барча транспорт хизматлари — битта иловада!  
**Қисқа:** Йўловчи ташиш, маршрутлар, шаҳарлараро сафар ва юк ташиш учун ягона платформа.

## Нима тузатилди (илова оқимига мос)

| Хизмат | Эски хато | Тўғри |
|--------|-----------|-------|
| Маҳаллий | «Ҳайдовчини танланг» | Йўловчи ҳайдовчи танламайди — яқинларга сўров; **биринчи қабул** қилган билан боғланади |
| Маҳаллий | «Масофа ва вақт» | Нарх **масофа + тариф** (база + км) бўйича |
| Маршрут | «Жой банд қилинг» | Бу шаҳарлараро тили; маршрутда **Чақириш** → тизим **навбат** бўйича |
| Шаҳарлараро | «Ҳайдовчи билан боғланинг» | Аввал **рейс танлаш + ўрин брон**; ҳайдовчи қабул қилади |
| Шаҳарлараро | «Масофага қараб келишилган нарх» | **Ўрин нарҳи** (ҳайдовчи белгилайди) × йўловчи сони |
| Юк биржаси | «Ҳайдовчилар таклиф юборади» | **Эълон + қидирув + қўнғироқ**; аукцион/таклиф оқими йўқ |

---

### 🚕 Маҳаллий такси
- **Ҳақида:** Манзилдан манзилга тез ва қулай такси.
- **Кимларга:** Ишга, ўқишга ёки шахсий ишларга ҳар куни қатнайдиганлар.
- **Буюртма:** Манзилни киритинг → Қидириш → биринчи қабул қилган ҳайдовчи билан боғланасиз.
- **Нарх:** Масофа ва тариф асосида автоматик ҳисобланади.
- **Афзаллик:** Тез чақириш · Яқин ҳайдовчи · Онлайн кузатиш · Хавфсиз сафар
- **Эслатма:** Ҳайдовчи маълумоти ва сафар ҳолати иловада кўринади.

### 🚐 Маршрут такси
- **Ҳақида:** Белгиланган МФЙ йўналиши бўйича умумий транспорт.
- **Кимларга:** Бир йўналишда арзон сафар истовчилар.
- **Буюртма:** Қаердан / қаерга МФЙ танланг → рейсларни кўринг → Чақириш (тизим навбат бўйича).
- **Нарх:** Йўналиш бўйича ягона (белгиланган) тариф.
- **Афзаллик:** Арзон · Доимий йўналиш · Йўловчига қулай
- **Эслатма:** Йўналиш ва жойлашув иловада янгиланиб туради.

### 🛣️ Шаҳарлараро такси
- **Ҳақида:** Шаҳардан шаҳарга хавфсиз ва қулай сафар.
- **Кимларга:** Бошқа шаҳарларга йўловчилар.
- **Буюртма:** Қаердан / қаерга + сана + ўрин → рейс танланг → брон қилинг (ҳайдовчи қабул қилади).
- **Нарх:** Ҳайдовчи белгилаган ўрин нарҳи × йўловчи сони.
- **Афзаллик:** Узоқ масофага ишончли · Олдиндан брон · Қулай нарх
- **Эслатма:** Сафардан олдин брон қилиш тавсия этилади.

### 🚚 Юк биржаси
- **Ҳақида:** Юк эгалари ва бўш машина эгаларини боғловчи эълон платформаси.
- **Кимларга:** Тадбиркорлар, дўконлар, ишлаб чиқарувчилар ва жисмоний шахслар.
- **Буюртма:** Юк ёки машина эълони қўйинг / қидиринг → қўнғироқ қилинг.
- **Нарх:** Эълонда кўрсатилган нарх (ҳажм, оғирлик, масофага қараб келишилади).
- **Афзаллик:** Юкни тез топшириш · Бўш машинани тез топиш · Тўғридан-тўғри боғланиш
- **Эслатма:** Юкнинг аниқ вазни, ҳажми ва манзилини кўрсатинг. Эълон ~48 соат фаол.
