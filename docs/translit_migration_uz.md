## 1. Хулоса

**Камчилик:** production'даги `marketToLatin` функцияси ўзбек кириллицасидаги `ъ` ва `ь`
ҳарфларини **олиб ташламайди** — улар лотин матнга ўзгармаган ҳолда тушиб кетади.

**Таъсир доираси бугун:** ўлчанди — **битта ҳужжат** (`ads` коллекциясида `истеъмол` сўзи).

**Шунинг учун бу шошилинч эмас.** Лекин бу **кутиб турган камчилик**: `ъ` ўзбек тилида
камёб ҳолат эмас, балки ҳақиқий ҳарф (**эълон, таъми, истеъмол, маълумот, таъмирлаш**).
Контент ўсган сари зарар ҳам ўсади ва у **жимгина** содир бўлади — хато чиқмайди, фақат
қидирув натижа бермайди.

**Тавсия:** тузатиш P1 shadow mode билан бир вақтда бажарилсин (битта белги ўзгаради,
reseed механизми аллақачон мавжуд). Шошилинч деплой керак эмас.

## 2. Камчиликнинг сабаби

```javascript
// functions/index.js:7210 — МАВЖУД ҲОЛАТ
function marketToLatin(s) {
  const map = {
    /* ... */ ъ: '', ы: 'i', ь: '', э: 'e', /* ... */
  };
  return String(s || '').toLowerCase().split('')
    .map((c) => map[c] || c)          // ← МУАММО АЙНИ ШУ ЕРДА
    .join('');
}
```

`map['ъ']` қиймати **бўш сатр**, бўш сатр эса JavaScript'да **falsy**. Шунинг учун
`||` оператори ишга тушади ва белги **ўзгармаган ҳолда** қайтарилади:

```
marketToLatin('курьер')  →  'kurьer'    (кутилган: 'kurer')
marketToLatin('эълон')   →  'eълon'     (кутилган: 'elon')
marketToLatin('истеъмол')→  'isteъmol'  (кутилган: 'istemol')
```

Жадвалда фақат иккита белги бўш сатрга хариталанган: `ъ` ва `ь`. Қолган ҳамма белги
бўш бўлмаган қийматга эга, шунинг учун улар тўғри ишлайди.

## 3. Уч томонлама ажралиш

| Томон | Файл | Код | «курьер» натижаси |
|---|---|---|---|
| **Production сервер** | `functions/index.js:7218` | `map[c] \|\| c` | `kurьer` ❌ |
| **Илова (Dart)** | `lib/features/ads/utils/ad_search_text.dart:65` | `map[c] ?? c` | `kurer` ✅ |
| **Янги ядро** | `functions_demand/core/text.js` | `hasOwnProperty` | `kurer` ✅ |

Dart'даги `??` (null-aware) оператори бўш сатрни **тўғри** қайтаради — калит мавжуд,
қиймати бўш. `||` (falsy-OR) эса бўш сатрни «йўқ» деб ҳисоблайди.

**Яъни илова ва янги ядро бир-бири билан мос; фақат production ажралиб турибди.**

Амалий натижа: кирилл «курьер» деб ёзилган эълон лотин «kuryer» сўрови билан топилмайди
(индексда `kurьer` тури, фойдаланувчи эса `kuryer` ёзади).

## 5. Тузатиш

### 5.1 Код ўзгариши (битта функция)

```javascript
// functions/index.js:7210
function marketToLatin(s) {
  const map = { /* ўзгармайди */ };
  return String(s || '')
    .toLowerCase()
    .split('')
    .map((c) => (Object.prototype.hasOwnProperty.call(map, c) ? map[c] : c))
    .join('');
}
```

`hasOwnProperty` ишлатилади, `??` эмас: `map[c] ?? c` ҳам тўғри ишларди, лекин
`hasOwnProperty` ниятни очиқ кўрсатади ва прототип занжиридан тасодифий калит
(`constructor`, `toString`) олинишидан ҳам ҳимоя қилади.

**Чақирув жойлари (текширилди):** функция фақат иккита жойда ишлатилади —
`index.js:7247` (`buildMarketSearchTokens`) ва `index.js:15204`
(`buildSearchIndexTokens`). Иккиси ҳам токен қурувчи, шунинг учун ўзгариш
бошқа мантиққа таъсир қилмайди.

### 5.2 Нима учун `ъ` → `''`, `ъ` → `'` эмас

Репо конвенцияси `ў` → `o'`, `ғ` → `g'` — яъни апостроф ишлатилади. Шу мантиқ бўйича
`ъ` → `'` бўлиши керак эди. Лекин:

1. **Илова аллақачон `''` қилади** (`AdSearchText`). `'` га ўтказиш иловани ҳам
   ўзгартиришни талаб қилади — иккита миграция ўрнига битта.
2. **Янги ядро канон шаклда апострофни умуман тушириб юборади** (`b27a253` commit'и):
   одамлар телефонда апостроф ёзмайди. Яъни `'` барибир йўқолади.
3. **Қидирув учун `''` рекол жиҳатидан яхшироқ:** «эълон» → `elon`, фойдаланувчи
   `elon` деб ёзади. `e'lon` бўлса апостроф ёзмаган одам тополмайди.

**Қарор: `''` (тушириб юбориш) — илова билан мос.**
