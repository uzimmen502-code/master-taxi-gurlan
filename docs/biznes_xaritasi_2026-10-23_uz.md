## Сервер (Cloud Functions, `functions/business_directory.js`)

Ҳамма ёзув callable орқали; Firestore rules'да `create/update/delete = false` (`china_inquiries` тартиби).

| Callable | Ким | Иш |
|---|---|---|
| `upsertMyBusiness` | эга | `businessId` йўқ → яратиш (`clientRequestId` бўйича идемпотент); бор → ўз ёзувини таҳрирлаш |
| `deleteMyBusiness` | эга | ўз ёзувини ўчириш (идемпотент) |
| `adminUpdateBusiness` | admin/superadmin | майдонларни таҳрирлаш, `reason` ≥ 3, `admin_audit` |
| `adminDeleteBusiness` | admin/superadmin | ўчириш, `reason` ≥ 3, `admin_audit` + snapshot |

Диагностика кодлари: `BUSINESS_NAME_INVALID`, `BUSINESS_CATEGORY_INVALID`, `BUSINESS_LOCATION_INVALID`,
`BUSINESS_PHONE_INVALID`, `BUSINESS_LIMIT_REACHED`, `BUSINESS_NOT_FOUND`, `BUSINESS_NOT_OWNER`, `REQUEST_ID_INVALID`,
`GEO_DISTRICT_INVALID`, `REASON_REQUIRED`. Фойдаланувчига код эмас, оддий жумла (25-банд).

Қайта чақирилса: яратиш — битта ҳужжат; ўчириш — иккинчи марта `changed:false`.
