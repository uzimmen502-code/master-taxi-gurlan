## 3. Архитектура (PROPOSED)

**`order_index`** — серверда ёзиладиган йиғма коллекция (фақат ҳозирги ҳолат;
тарих манба коллекцияларида қолади, 16-қоида):

- ID: `{module}_{sourceId}`; майдонлар: `module`, `sourceCollection`,
  `sourceId`, `normStatus`, `rawStatus`, `statusSince`, `courierId`,
  `amount` (бутун сўм), `regionId`/`districtId` (бор бўлса), `createdAt`,
  `updatedAt`, `customerTail` (телефоннинг охирги 4 рақами — тўлиқ PII йўқ, 40-қоида).
- Ҳар манба коллекциясига `onWrite` триггер; ягона ҳолат жадвали битта
  серверда файлда (7, 17-қоида). Танилмаган статус → `UNKNOWN` + structured log.
- `statusSince` — `normStatus` ўзгарганда триггер қўяди (модулларда
  ягона «ҳолатга ўтган вақт» майдони йўқ: нон буюртмасида `readyAt` йўқ,
  гилам/сутда фақат `updatedAt` — CONFIRMED).
- Идемпотент: ҳужжат ID детерминистик, эскирган event `updatedAt` бўйича
  устидан ёзмайди (21, 23-қоида).
- Клиент ёзолмайди (rules `write: false`).
- Эски буюртмалар: backfill воситаси (dry-run → batch → текширув → rollback;
  27-қоида). Эски ҳужжатларда `statusSince` = `statusUpdatedAt` / `updatedAt` /
  `createdAt` — **тахминий** (INFERRED) деб белгиланади.
- Нарх: ҳар статус ўзгаришида +1 ёзув; экран 7 та listener ўрнига битта
  саҳифаланган сўров.

Ягона ҳолатлар: **Янги → Қабул қилинди → Курьер кутмоқда → Курьерда →
Етказилди / Бекор**.

## 5. Рухсат модели (PROPOSED)

**Ҳозир (CONFIRMED):** бўлим кўриниши фақат ролга боғлиқ
(`_SectionAccess`, admin_shell.dart); алоҳида одамга бўлим рухсати
берадиган механизм **йўқ**. Ролни фақат `setUserRoleByAdmin` ўзгартиради
(admin — фақат `user`/`seller`; имтиёзли ролни фақат superadmin), лекин
бу `admin_audit`га ёзилмайди.

**Таклиф:**
- Янги `admin_grants/{телефон}` ҳужжати, майдон `allOrdersView: true`.
  Клиент ёзолмайди; фақат callable `adminSetGrant` (ким бера олади: admin ва
  superadmin) — ҳар бериш/олиш `admin_audit`га (41-қоида).
- Фақат панел ролли одамга берилади (`admin/dispatcher/finance/auditor`);
  superadmin ҳар доим кўради.
- Сайдбарда таб фақат рухсати борга; rules `order_index` ўқишни ҳам шу
  рухсат билан чеклайди (UI — манба эмас, 44-қоида).
- Рухсат бериш тугмаси — «Фойдаланувчилар» бўлимидаги мавжуд рол
  тугмалари ёнида (`_UserRoleActions`).

## 6. Экран (PROPOSED)

- Тепада: ҳолатлар бўйича сонлар + «Тиқилиб қолган».
- Фильтр: модул, ҳолат, сана, ҳудуд, «фақат тиқилиб қолганлар»; қидирув —
  буюртма ID ёки телефоннинг охирги 4 рақами.
- Қатор: модул белгиси, ҳолат, ҳолатда турган вақт, сумма, курьер бор/йўқ.
- Босилса — фақат кўриш ойнаси (индекс маълумоти + «модул бўлимида очиш»
  тугмаси, агар ролига рухсат бўлса).
