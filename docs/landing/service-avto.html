Гилам ювиш

Олиб кетиш → ювиш → қайтариш

Гилам сони ва манзилни киритиб буюртма берасиз — буюртма бергандан сўнг диспетчерга автоматик қўнғироқ очилади. Курьер гиламни олиб кетади, ювилгач қуритилади ва белгиланган манзилга қайтарилади.

  • Аниқ ҳолат Янги → Қабул қилинди → Олиб кетилди → Ювилмоқда → Қуритилмоқда → Тайёр → Йетказилди.
  • Менинг буюртмаларим Барча буюртмалар тарихини бир жойда кузатасиз.
Мой алмаштириш

Моделга қараб тавсия, кейин брон

Машина маркаси, модели, йили ва двигателига қараб тавсия берилади (VIN даражасидаги аниқлик эмас) — мотор ва фильтр учун керакли мой ҳажми кўрсатилади. Сўнг пакет, пункт ва вақтни танлаб брон қиласиз.

  • Тўғри танлов Мос келмаган мой — ортиқча харажатга олиб келиши мумкинлиги алоҳида таъкидланади.

Тез-тез сўралади

Гилам ювиш учун қаерга олиб бориш керакми?

Йўқ — курьер уйингиздан олиб кетади ва ювилгач қайтариб беради.

Мой тавсияси VIN бўйича аниқми?

Йўқ, тавсия марка/модель/йил/двигателга асосланади — VIN даражасидаги аниқлик берилмайди.
