## Маълумот модели

| `ownerId` | string | 12 хонали телефон-uid (токендан, клиентдан эмас — 18-банд) |
| `name` | string 2–80 | |

| `subtype` | string ≤ 60 | эркин матн («авто-мойка», «дорихона») |
| `description` | string ≤ 500 | |

| `address` | string ≤ 200 | |

| `geohash`, `geohash4` | string | СЕРВЕР ҳисоблайди (`functions/geo_hash.js`) |
| `regionId`, `districtId` | string | ихтиёрий; бор бўлса `geo_districts`да мавжудлиги ва вилоятга мослиги текширилади |
| `openingHours` | string ≤ 120 | |

| `status` | `active` | 1-босқичда ягона қиймат; бўлажак яширишга жой |
| `createdAt`, `updatedAt` | timestamp | |

Тариф/пул майдонлари йўқ. Эски ҳужжат йўқ (янги коллекция) — миграция керак эмас.

## Сервер (Cloud Functions, `functions/business_directory.js`)

Ҳамма ёзув callable орқали; Firestore rules'да `create/update/delete = false` (`china_inquiries` тартиби).

| Callable | Ким | Иш |
|---|---|---|
| `upsertMyBusiness` | эга | `businessId` йўқ → яратиш (`clientRequestId` бўйича идемпотент); бор → ўз ёзувини таҳрирлаш |
| `deleteMyBusiness` | эга | ўз ёзувини ўчириш (идемпотент) |
| `adminUpdateBusiness` | admin/superadmin | майдонларни таҳрирлаш, `reason` ≥ 3, `admin_audit` |
| `adminDeleteBusiness` | admin/superadmin | ўчириш, `reason` ≥ 3, `admin_audit` + snapshot |

Диагностика кодлари: `BUSINESS_NAME_INVALID`, `BUSINESS_CATEGORY_INVALID`, `BUSINESS_LOCATION_INVALID`,
`BUSINESS_PHONE_INVALID`, `BUSINESS_LIMIT_REACHED`, `BUSINESS_NOT_FOUND`, `BUSINESS_NOT_OWNER`, `REQUEST_ID_INVALID`,
`GEO_DISTRICT_INVALID`, `REASON_REQUIRED`. Фойдаланувчига код эмас, оддий жумла (25-банд).

Қайта чақирилса: яратиш — битта ҳужжат; ўчириш — иккинчи марта `changed:false`.

## Rules

`businesses`: `allow read: if isAuth()` (логин қилган фойдаланувчи; телефон/манзил логинсиз скрапингга очилмасин, 40-банд — PROPOSED, `restaurants`дан қатъийроқ); `write: false`.

## Харитага ўқиш режаси (кластерсиз)

Тўрт манба БИР вақтда, камера ҳудудини қоплайдиган `geohash4` катакчалари бўйича (≤ 30 катак, `whereIn` чегараси):

| Манба | Шарт | Эслатма |
|---|---|---|
| `businesses` | `geohash4 in cells` | янги, индекс керак эмас (битта майдон) |
| `restaurants` | `status=='approved'`, `geohash` префикс диапазони | мавжуд `watchNearby` услуби |
| `ev_charging_stations` | `isActive`, `geohash4 in cells` | мавжуд `watchNearby` услуби, ўқиш — логин керак |
| `wholesale_sellers` | `approvalStatus=='approved'`, координатаси бор | геохеш йўқ → ≤ 300 та, мижоз томонида ҳудуд фильтри |

- Масштаб жуда кичик бўлса (катакчалар > 30) — «яқинлаштиринг» ёзуви, ўқиш йўқ.
- Ҳар манбадан харитада ≤ 400 маркер.
- Камера тўхтагандан кейин (debounce) бир марта сўров, ҳар кадрда эмас (36-банд).

## Тест режаси

- Rules: `businesses` ўқиш очиқ; клиент `create/update/delete` — рад.
- CF: яратиш (идемпотент), чегара, нотўғри тур/координата/телефон, бегона ёзувни таҳрирлаш/ўчириш рад, админ таҳрир/ўчириш + audit.
- Dart: модел парсинг, тур рўйхати паритети, катакчалар ҳисоби, адаптерлар (4 манба), экран виджет тестлари.

## Deploy (босқичма-босқич)

1. Functions — ном бўйича (4 та), пинланган worktree'дан.
2. Rules — алоҳида команда, `--config <abs>\firebase.json` (янги `businesses` блоки; бошқа ҳунк йўқ).
3. Hosting — жонли SHA устига; модул OFF.
4. Админ «Ҳудудлар ва хизматлар»да `business_map` ни пилот туманга ёқиш.

Орқага қайтариш: hosting — олдинги release; rules — олдинги ruleset (ID ҳисоботда); functions — 4 та callable ўчирилади (маълумотга таъсир қилмайди).
